A repository containing Russian, English, and Chinese translation files for the LOTR Reworked 2.+ mod for Minecraft 1.12.2

If you are a translator for another language and would like to create your own translation, please use the Language Packs system (more details here -> https://lotr-reworked.fandom.com/ru/wiki/Language_Packs)
